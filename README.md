# E-Commerce Project

A full-stack e-commerce application currently under development.

## Current Progress

### Backend

The backend is being developed using Spring Boot.

Currently implemented:

* Category CRUD APIs
* Create category
* Get all categories
* Update category
* Delete category
* Spring Data JPA
* REST APIs
* H2 Database
* Controller-Service-Repository architecture

## Tech Stack

### Backend

* Java 21
* Spring Boot
* Spring Data JPA
* Maven
* H2 Database
